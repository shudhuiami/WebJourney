# WebJourney — Logo Pack

Based on the approved WebJourney concept: a teal path leading into an orange location pin and pointer, with green “Web” and slate “Journey.” These are freshly drawn, clean scalable SVG assets matching the approved visual direction; not pixel-exact crops of the reference board.

## Included
- 01_Primary_Logo — horizontal (with/without tagline), stacked, and standalone wordmark; SVG and transparent PNG.
- 02_Icon — transparent icon and light/dark square app icons; SVG and PNG.
- 03_Chrome_Extension — ready-sized PNG icons (16, 32, 48, 128, 512 px), 512 px store asset, and favicon.ico.
- 04_One_Color — dark and white one-color variants; SVG and PNG. The white-on-slate version includes a preview background; the white-transparent file is the actual reversed asset.
- 05_Brand_Guide — palette as an SVG/PNG chart.

## Brand palette
Jungle Green #0B9981 — primary “Web” wordmark and active UI
Teal #087F72 — path / dark accent
Sunset Orange #FF9E0B, orange-deep #FF8128 — pin, highlights and CTAs
Warm Cream #FFF7E6 — optional warm background
Mint #ECFDF5 — soft surface
Slate #1E293B — “Journey” wordmark and principal body text
Muted Gray #64748B — secondary text

## Usage
- Preferred default: WebJourney_Horizontal.svg over white / light backgrounds.
- Small spaces: WebJourney_Icon_Transparent.svg or AppIcon_Light.svg.
- Very dark surfaces: WebJourney_White_Transparent.svg or AppIcon_Dark.svg.
- SVG artwork has embedded vector outlines (no font files are bundled); the optional tagline is live SVG text with fallbacks.
- Chrome uses PNG manifest icons. At 16 px the tiny secondary details may disappear, so verify in the actual browser toolbar.
- Maintain clearspace around the icon (at least 10% of its visible width); avoid stretching or changing the color of “Web” to dark blue.

Source of inspiration: user-approved WebJourney brand board; redraw is optimized for practical logo applications.
