# WebJourney — Chrome Web Store Listing Package (WJ-503)

## 1. Product Title
**WebJourney — Interactive Website Guidance & Walkthroughs**

## 2. Short Summary (Max 132 chars)
Create and follow interactive step-by-step walkthroughs on real websites. Learn by doing with zero code changes.

## 3. Detailed Description
WebJourney is a modern Chrome extension that lets you build, publish, and play step-by-step interactive website walkthroughs directly inside live web applications — without touching the website's source code!

### 🌟 Why WebJourney?
Traditional onboarding videos and PDF guides are disconnected from the actual work. With WebJourney:
- **Teach By Doing**: Learners follow visual spotlights and contextual tooltips on the live application.
- **Action-Driven Progression**: Steps advance only when the learner performs the real action (clicking a button, entering a field, or navigating to a route).
- **100% Isolated UI**: Uses an encapsulated Shadow DOM overlay so host website styles never corrupt your tour.
- **Zero Privacy Invasiveness**: We never record typed passwords, form values, session cookies, or user browsing history.

### 🛠️ Key Features:
- **Visual Element Picker**: Click any button, link, or input to instantly turn it into an interactive step.
- **Multi-Heuristic Target Resilience**: Intelligent selector fallback that adapts to dynamic DOM updates.
- **Chrome Side Panel Builder**: Edit instructions, reorder steps, preview live overlays, and organize drafts.
- **Share Codes & Invitations**: Publish immutable journey versions and share instant `WJ-XXXXXX` invite codes with learners.
- **Pause, Resume & Error Recovery**: Full control for learners with fallback instructions and step skip options.
